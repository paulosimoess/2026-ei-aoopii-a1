## Descrição do projeto
Este projeto tem como objetivo desenvolver uma aplicação de filtros faciais em tempo real, utilizando a webcam do utilizador. A aplicação irá detetar pontos de referência da face e sobrepor elementos gráficos, como chapéus, óculos, máscaras ou outros efeitos visuais, acompanhando os movimentos do rosto em direto.

A ideia é criar uma experiência interativa de realidade aumentada, inspirada em aplicações como Snapchat, Instagram e TikTok, explorando técnicas de visão por computador e renderização em tempo real.
